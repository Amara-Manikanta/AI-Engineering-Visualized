# AI Engineering Visualized 🤖

### Understand AI. Don't just use it.

AI is moving incredibly fast.

New models, frameworks, agents, RAG architectures, tools and techniques appear every day.

But one thing hasn't changed:

**If you don't understand what is happening underneath, you're only using the magic.**

This project is my attempt to make AI engineering **visible, understandable and interactive**.

---

## 🧠 My Motto

> **Don't just learn what AI does.  
> Visualize how it works.**

Instead of explaining AI with pages of text, I want to turn complex ideas into things you can **see, explore and understand**.

From:

**Tokens → Embeddings → Attention → Transformers → RAG → Agents → Tools → Memory → Models → Systems**

I want to show what is actually happening behind the scenes.

---

## 🔬 What is this?

**AI Engineering Visualized** is an interactive knowledge base for understanding modern AI engineering.

It explores concepts through:

- 🧩 Interactive visualizations
- 🏗️ Architecture diagrams
- 🔄 Data-flow visualizations
- 🧠 Model internals
- 🔍 RAG pipelines
- 🤖 AI agents
- ⚡ LLM inference
- 📦 Embeddings & vector databases
- 🔧 Tools, MCP & agent systems
- 💻 Practical experiments
- 📚 Technical deep dives

The goal isn't to collect tutorials.

The goal is to build **intuition**.

---

## 👀 Learn by Seeing

Instead of:

> "A transformer uses self-attention."

See it.

Instead of:

> "RAG retrieves relevant chunks."

Watch the query move through:

`Query → Embedding → Retrieval → Reranking → Context → LLM → Answer`

Instead of:

> "An AI agent uses tools."

See:

`Goal → Reason → Tool → Observation → Reason → Action → Result`
